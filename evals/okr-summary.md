# OKR Summary behavioral evaluation

Choose a closed OKR with an accepted quarterly comment. Keep the example with the evaluator. Give each fresh writer the same OKR, reporting period, audience and complete source snapshot. An older quarterly update can be valid evidence. Exclude the target comment itself from the writers' inputs. Keep private tickets, drafts and review traces outside this repository.

## Compare drafting modes

Keep the writer's model, effort and evidence constant when comparing work done solo with delegated work. For an evidence analyst, retain the analyst's findings and check which source-backed results and private cautions appeared in the final comment. For a draft reviewer, retain the first complete draft and compare it with its revision. Keep intermediate artifacts only for the evaluation.

Give an evaluator the reference, source evidence and anonymized candidates. Include the previously used skill's output when available. Judge each candidate on the same questions before revealing which workflow produced it.

- Can a sponsor read just the opening and identify the final state of each primary commitment, its operational significance and the basis for the criteria statement?
- Does the evidence explain the delivered capability, user experience, reach and verification? Check material dates, populations, data limitations, ownership transfers and named documents against the sources.
- Does the scope distinguish completed work, open obligations and separately chosen improvements? Can the reader follow the decision and each material follow-up?
- Would a statement imply a stronger result than the evidence shows? Look for defect-fix dates inferred from test closure, targets presented as measured gains, or client outreach described as completed adoption.
- Is the output one copyable Markdown comment in the requested language? Check that a plain-language edit retained qualifications and that the readership needs each technical detail.

Treat an unsupported central claim as a defect even if the wording resembles the reference. Record which points were complete, partial or missing and the corrections that changed the ranking. Confirm the selected workflow once through the installed skill on a fresh run.

When comparing reasoning levels, give each writer the same analyst brief to isolate the writing decision. Also try an ordinary invocation at each level to measure end-to-end behavior. Check that the writer called the analyst and read the English editing skill. To evaluate the final coverage check, keep the draft before and after it and present both anonymously. Report elapsed working time and estimate the cost of both roles from uncached input, cached input and output at the applicable rates. Include the writer's final pass and count a shared brief at its full cost for each standalone estimate. Report evaluation costs separately if requested.
