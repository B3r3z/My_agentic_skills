# Strict vocabulary review

Use the dictionary and writing rules from the requested edition of [ASD-STE100](https://www.asd-ste100.org/). This skill targets Issue 9 when the user does not specify an edition. A plain-English synonym list cannot establish approval.

1. Set aside literal commands, error strings, UI labels, and identifiers. Review the surrounding prose. If a literal creates a problem, quote it so the reader can still find it.
2. For each word in ordinary prose, check the dictionary entry for its meaning, part of speech, and permitted form in this sentence. A listed noun does not automatically qualify as a verb.
3. For a domain term, check the edition's provisions for technical nouns or verbs and any project terminology supplied by the user. Use the chosen term consistently.
4. When a substitution changes the action or its certainty, recast the sentence. Read the result against the source before accepting it.

For example, “Confirm the deletion” can mean that the operator must approve a pending action or check that an earlier action finished. Establish which action the source describes before choosing a verb.

For a compliance review, state which edition and material you checked. If the official dictionary is unavailable, give the supported clarity edits and say that vocabulary compliance remains unverified. If a term or rule is unresolved, identify it without assigning a rule number from memory.
