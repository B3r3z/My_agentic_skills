# Domain documentation configuration seed

Record actual paths in `AGENTS.md`: glossary (`CONTEXT.md` by default), ADR directory (`docs/adr/`), and an existing context map if present.

Use conditional guidance: consult the relevant glossary when domain terminology or relationships affect the task; consult relevant ADRs when a design choice touches their constraints. Follow only relevant context-map links. Do not require all documentation before every edit.

Missing documents do not block ordinary work. Create them only during authorized documentation work when a term or consequential decision is resolved. Surface conflicts with existing decisions rather than silently replacing them.
