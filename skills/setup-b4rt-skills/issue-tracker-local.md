# Local task configuration seed

Record the local task directory in `AGENTS.md`, default `.scratch/<feature-slug>/issues/`. One Markdown file per task, with stable ID, acceptance criteria, local dependencies, and status. Preserve existing IDs and files on revision.

All `to-tickets` inputs and updates are local. External references may be kept as plain text; no fetching, publishing, or synchronization. Its `ready-for-agent` status means specified, and dependencies determine whether execution can begin. No remote labels or credentials are required.
